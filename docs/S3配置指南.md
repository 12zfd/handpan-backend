# Cloudflare R2 配置指南

## 为什么需要 R2？

Render Free 使用本地磁盘存储，存在以下问题：
- 容器重启后文件丢失
- 下载速度受限于 0.1 CPU
- 冷启动延迟高

R2 提供：
- 永久存储（不丢数据）
- CDN 加速（全球下载）
- 免费额度：10GB 存储 + 100万次读取/月

## 配置步骤

### 1. 创建 R2 Bucket

1. 登录 Cloudflare Dashboard
2. 进入 R2 → Create Bucket
3. 命名：`handpan-pdfs`（或自定义）
4. 区域：选择 closest（自动）

### 2. 创建 API Token

1. R2 → Manage R2 API Tokens
2. Create Token
3. 权限：Object Read & Write
4. 复制保存：
   - Access Key ID
   - Secret Access Key

### 3. 配置 Render 环境变量

在 Render Dashboard → handpan-backend → Environment：

```
S3_BUCKET=handpan-pdfs
S3_ENDPOINT=https://acc5f37e5e5d4e9db0e5c5e5e5e5e5e5.r2.cloudflarestorage.com
S3_KEY=your_access_key_id
S3_SECRET=your_secret_access_key
S3_REGION=auto
```

**注意：** endpoint URL 格式为：
`https://{account-id>.r2.cloudflarestorage.com`

获取 account-id：
- R2 Dashboard → 页面底部 "Account ID"

### 4. 验证配置

部署后测试：
```bash
curl https://handpan-backend.onrender.com/healthz
```

上传新任务后，检查：
- 数据库 `pdf_url` 字段（key）
- R2 Bucket 是否有对应文件
- 下载速度是否提升

## 迁移现有数据

如果需要迁移本地 PDF 到 R2：

```bash
# 在 Render 服务器执行（或通过 SSH）
cd /var/data
for f in pdfs/*.pdf; do
  rclone copy $f r2:handpan-pdfs/pdfs/
done
```

或使用 Python 脚本批量上传。
